## How to Run

1. 确保已安装 Docker 和 Docker Compose

2. 在项目根目录执行：
```bash
docker-compose up --build -d
```

3. 访问应用：
- 用户端: http://localhost:8081

4. 停止服务：
```bash
docker-compose down
```

## 测试

### 测试音频

项目提供了测试音频文件 `frontend-user/public/test-guqin.wav`，可直接用于测试：
- 基频: 130.81 Hz (接近 C3)
- 时长: 3 秒
- 包含 13 次谐波，模拟古琴音色

### 功能测试

1. 上传音频文件
   - 支持 MP3、WAV、OGG 等常见音频格式
   - 文件大小建议不超过 10MB
   - 音频时长建议在 5 秒以内

2. 区间选择
   - 使用输入框精确输入起止时间（毫秒）
   - 使用滑块快速选择区间
   - 实时显示选中时长

3. 音频分析
   - 点击"分析音频"按钮开始分析
   - 自动检测基频
   - 显示最多 13 倍频

4. 音色判定（按谐波说话）
   - 音准：检测基频与最近十二平均律音的偏差（音分）
   - 谐波衰减：第 3~8 谐波相对基频能量的线性拟合斜率（dB/倍频程）
   - 自相关法与峰值检测分别下结论并互相印证，不一致时取更保守的一档
   - 给出 **合格 / 存疑 / 不合格** 三档；判定口径直接显示在结果旁
   - 谐波能量太弱（可测谐波不足或电平过低）时判为 **数据不足**，不判不合格，提示重选区间
   - 判定口径可在左侧"音色判定口径"面板调整，自动持久化，更换音频文件后原样保留

5. 多区间对比
   - 可对同一段音频依次选择多个区间分析，结果并排进入对比列表
   - 超出合格/存疑参考范围的指标用橙、红底色单独标出
   - 点击行可回看该区间的图表与判定详情，可单段移出或一键清空
   - 修改判定口径后，所有已分析区间会按新口径自动重判

6. 图表验证
   - 波形图：显示选中区间的音频波形
   - 频谱图：显示基频和倍频的相对强度
   - 热力图：显示声强随时间的变化
   - 频率区域图：分别显示低频区、中频区、高频区

# 古琴音频分析软件

专为斫琴师设计的音频频谱分析工具，用于分析古琴音色的基频、倍频和声强变化。

## 功能特性

- **音频上传**：支持 MP3、WAV、OGG 等常见音频格式
- **精确截取**：以毫秒为单位精确选择分析区间
- **基频检测**：自动检测音频的基频
- **倍频分析**：显示最多 13 倍频，过滤其他频率
- **可视化图表**：
  - 波形图：显示音频波形
  - 频谱图：显示基频和倍频的强度分布
  - 热力图：显示声强随时间的变化
  - 频率区域图：分别显示低频区、中频区、高频区

## 技术栈

- 原生 JavaScript (ES6+)
- Web Audio API
- Chart.js
- Vite
- Nginx
- Docker

## 频率区域说明

- **低频区**：基频 ~ 4倍频
- **中频区**：5倍频 ~ 8倍频
- **高频区**：9倍频 ~ 13倍频

这三个区域共享同一个基频，用于分析古琴音色在不同频率范围的特征。

## 音色判定口径

判定严格"按谐波说话"，默认口径如下（可在界面调整，修改即自动保存并重判）：

| 项目 | 合格 | 存疑 | 不合格 |
|------|------|------|--------|
| 音准偏差（检测基频对最近十二平均律音） | ≤ 15 音分 | ≤ 30 音分 | > 30 音分 |
| 第3~8谐波能量衰减斜率 | -18 ~ -6 dB/倍频程 | -24 ~ -3 dB/倍频程 | 超出存疑范围 |

- **双路互证**：自相关法与峰值检测各自独立下结论；两路基频相差 ≤ 50 音分视为互相印证。
- **保守合并**：音准与衰减两项、两路方法之间，一律取更保守（差）的一档；两路不一致时即使各自合格也降为存疑。
- **数据不足**：第3~8谐波中可测（不低于基频能量 -60 dB）个数 < 3，或区间 RMS < 0.005 时，只提示"数据不足、请重选区间"，不判为不合格。
- **口径持久化**：口径存于 localStorage（`guqin_timbre_criteria`），换文件、刷新页面均原样保留；每条历史记录同时保存判定时的口径快照。
